# data09-23 · 행복회로 버킷리스트

복권에 당첨됐다고 가정하고 버킷리스트를 비용과 함께 적으면, 남은 예산과 「몇 달을 살 수 있나」가 바로 바뀌는 가상 시뮬레이터 — 로또·스피또는 일시금 예산, 연금복권은 월별 현금흐름

| 항목 | 내용 |
|---|---|
| 제출자 | 이영우 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-09-29), 수강생 답변 반영 (2026-09-30, 기획서 v0.2) — https://aebonlee.github.io/data09-23/ |
| 다음 개발 | 2단계 — 로또 자료 채우기(공식 경로 확인 뒤 예약 작업 또는 관리자 등록), 스피또 회차별 등위표, 랜덤 추천, 계정·동기화·공유 링크 철회 |

> **가상 시뮬레이션입니다.** 실제 당첨·계좌·재무 조언이 아니며, 세금은 수강생 기획서 2장 산식의 원 단위 추정치입니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data09-23/**

처음 열면 빈 시나리오입니다. 「예시」 단추로 기획서 5장의 계산 예시(일시금 20억원 · 연금복권 1등 · 연금 1등 + 2등 4매)를 새 시나리오로 불러올 수 있습니다. 입력은 이 브라우저에만 자동 저장됩니다(계정 없음).

내 PC에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN·라이브러리를 부르지 않습니다.

| 화면 | 하는 일 |
|---|---|
| 1. 당첨 내역 | 복권(로또 6/45 · 연금복권720+ · 스피또500/1000/2000 · 직접 설정)·등수·수량·1건당 세전/세후 금액·수령 월(연금은 첫 지급 월·지급기간). 세전×수량·예상 세금·세후 합계 즉시 표시. 프리셋 3종, 같은 게임 중복 차단 |
| 2. 잔고와 안전금고 | 현재 잔고, 「이 돈은 남겨둘래요」 안전금고, 시작 월, 월별 보기. 한도 식을 풀어서 표시(월별 = 현재 잔고 + 시작 월 수령액 + 추가 예상 수입) |
| 3. 버킷리스트 | 추가·수정·보류·삭제(되돌리기), 「이거 포기하면?」 비교, 카테고리·우선순위 필터와 정렬, 카테고리별 합계. 금액은 「1억 8천만」처럼 적어도 됩니다 |
| 4. 고정지출·기타 수입 | 월 금액·기간·「퇴사하면 멈춤」 (월별 계산). **추가 예상 수입** — 이름 생략 가능, 기간 필수, 그 기간 예산과 안전금고 한도에 들어감 |
| 남은 예산 / 선택 월 결과 | 일시금: 세후 당첨금·당첨 후 잔고·버킷 합계·계획 후 잔고·가용잔고·경고. 월별: 월 이동·첫 부족 월로·이번 달 수입/지출/잔여·누적/가용·지급 잔여 |
| 퇴사 가능 기간 | 안전금고를 지키며 버티는 개월 수(보조: 현금 기준) |
| 미래 현금흐름 | 누적 잔액 그래프(안전금고 기준선·연금 종료·첫 부족) + 같은 내용의 월별 표. **보기 기간 선택**(시작·끝 월, 1년·3년·10년) |
| 저장과 공유 | 여러 시나리오, JSON 내보내기·가져오기, 공유 이미지(PNG, 현재 잔고·메모 기본 숨김), 인쇄/PDF, **공유 링크**(주소 `#share=`, 서버 없음) |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 55개) — 기획서 5장 계산 예시 전부와 세금 구간 경계(200만원 · 3억원 · 6,600만원 기본액), 로또 평균·추가 예상 수입·그래프 기간·공유 링크
- DB 스크립트 검증: `./scripts/sqltest/run.sh` (로컬 PostgreSQL 필요)

## 1단계 구현 범위

| 기획서 기능 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 여러 복권·등수·수량, 세전/세후, 세금 구간 | 완료 | 과세 단위별 세후 × 수량(합계로 다시 과세하지 않음) |
| 연금복권 월별 현금흐름 | 완료 | 월 지급 1등 546만·2등·보너스 78만(기획서 기준 값, 고쳐 쓰기 가능). **20년 총액은 참고 정보이며 잔고에 더하지 않음** |
| 잔고·안전금고·버킷·경고·포기 비교·퇴사 기간 | 완료 | 기획서 3·6장 규칙대로 |
| 저장·백업·공유 | 완료 | localStorage + JSON, PNG 이미지·인쇄, 공유 링크(2026-09-30). 링크 철회는 2단계 |
| 로또 1~3등 평균 | 자료 읽기 완료 / 수집 보류 | `data/lotto.json` 이 있으면 최근 52회차 평균을 자동으로 채우고, 없으면 직접 입력·회차별 금액 평균 내기. 공식 공개 경로가 없어 자동 수집은 보류(기획서 11.2) |
| 스피또1000·2000 하위 등수 | 2단계 | 기획서에 1등 금액만 있어 나머지는 직접 입력 |
| 랜덤 추천, 계정·동기화 | 2단계 | DB 스키마·검증 하네스는 준비됨 |
